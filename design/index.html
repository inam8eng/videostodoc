The short answer

This box carries the direct answer at the top of a question article, so a reader and an AI both get the point in five seconds. It uses the orange wash, never a second accent color.

This is the lead paragraph style. It sits a little darker than body text that follows, because the first lines carry the moment of recognition that opens every article on this site.

This is regular body text. It runs at a comfortable reading size with a relaxed line height, and links look like this link. Bold text is used for the one thing that matters in a paragraph, not for decoration.

A section heading with the node dot

Each H2 gets a small orange node before it, the same node language as the Designesh mark. H3 headings stay plain and quiet.

  • List items get orange markers and calm spacing.
  • A second item, because lists should earn their place.
