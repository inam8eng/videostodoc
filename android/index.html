Install it in a minute

1

Tap Download

Your phone may warn that this kind of file can be harmful. Android shows that for every app that isn't from the Play Store. Tap Download anyway.

2

Open the file

Tap the finished download. If your phone asks, allow your browser to install apps: a settings page opens, turn on Allow from this source, then go back.

3

Tap Install

If Play Protect asks about the app, tap More details, then Install anyway. VideoDoc then opens like any other app. New versions will be on this page.
