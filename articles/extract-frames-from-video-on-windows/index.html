How to extract frames from a video on Windows, one frame or all of them

Inam Ul Haq·Updated October 14, 2026·9 min read
The short answer

If you need one frame from a video on Windows, pause it in VLC and press Shift+S, or use the Save a frame option inside the Photos app. To extract many frames without spending money, turn on the scene filter in VLC or run a quick ffmpeg command. Neither option tags the files with their place in the timeline or clears out extra copies. VideoDoc extracts every frame at 1, 2 or 4 frames per second, names each file by its timestamp, and drops duplicate pictures.

Last Updated: October 14, 2026.

You have a video saved on your Windows computer and you need image files from it instead of text. You might want a slide from a recorded class, a step from a software guide, or a quick picture from a family clip. Windows handles the simple part easily, but people run into trouble when they need to export pictures in bulk.

To grab one image, open VLC and press Shift+S. To export hundreds of images, Windows has no built-in tool, so you need VLC's scene filter, ffmpeg or a dedicated application. I will walk through where each free method runs into limits, because those boundaries matter depending on what you need.

What can Windows do on its own?

Newer updates to the Photos app let you pull a single picture out of a video file. Open your clip in Photos, pause where you want, and select Save a frame from the menu near the timeline. An answer on Microsoft's Q&A forum says this feature is in Photos version 2024.11070.31001.0 and higher, though several users in that thread missed it because the menu layout changed across updates.

Snipping Tool offers another simple way to capture a frame without extra software. Pause your clip, hit Windows+Shift+S, and crop a box over the display. This works on any playing video, but it grabs your screen resolution rather than the source video file. That means a 4K file playing on a 1080p display yields a 1080p picture, and a small video window leaves you with a tiny image.

Both choices output just one picture for every action you take. That works fine if you want a simple thumbnail or an image for a chat, but it gets tedious when you need forty clean pictures from a video presentation.

How do you save one frame at full quality with VLC?

VLC is a free media player that many Windows users already have, and it works better for taking a single picture. I use it myself whenever I only need one quick image. Pause the video on your frame and press Shift+S, or go to the Video menu and select Take Snapshot. VLC outputs a full-resolution PNG file directly from the video source into your Pictures folder, and it names the file starting with vlcsnap followed by the system date and time.

That naming habit creates a real headache later on. The output file tells you when you pushed the keyboard shortcut, but it gives no clue where that frame sits in the video. After a long study session, you end up with a folder full of vlcsnap files and no easy way to match a picture back to its original video timestamp without scrubbing through the clip again.

Can VLC save every frame for free?

VLC can export continuous frames if you enable an advanced option called the scene video filter. Open VLC, go to Tools, then Preferences, select All at the bottom under Show settings, and go to Video, then Filters, where you tick Scene video filter. Next, go into the Filters subsection, click Scene filter, and enter your destination folder, file prefix, and recording ratio. The University of Michigan published a step by step guide with screenshots covering every menu field.

The recording ratio value trips up almost everyone who tries it, so it helps to clarify how it works. This setting measures video frame counts instead of seconds. VLC's own documentation explains that setting a ratio of 3 exports one image for every three frames played, while the default value is 50. If your video runs at 30 frames per second, a setting of 30 produces roughly one picture each second, while that same setting on a 25 frames per second file extracts slightly more than one image per second.

You have to play the clip through, and VLC writes out pictures while it runs. That means an hour-long recording takes a full hour to process completely. The output files save as scene00001.png and scene00002.png in PNG format, so they fill up storage quickly. The filter does not check for duplicate frames, and it never puts timestamps into file names. Users have also reported missed or repeated frames when setting the ratio to 1, so do not count on it for capturing every single frame. Once you finish, remember to turn off the filter, or VLC will continue dumping images every time you play any file.

How do you extract frames with ffmpeg on Windows?

ffmpeg is a free command-line utility that underpins many popular media applications, and it gives you the most reliable free output. It does not come preinstalled with Windows. You download a Windows distribution from the ffmpeg download page, extract the archive, and either add its bin folder to your system PATH or execute the binary directly from Command Prompt.

Running a single command starts the process: ffmpeg -i lecture.mp4 -vf fps=4 frame_%05d.jpg. In this example, fps=4 tells the tool to write four images for each second of media, and %05d creates a five-digit numbered index so your pictures sort cleanly in File Explorer. Processing usually finishes much faster than real-time playback because the tool does not have to play the video on your display.

It shares the same major limitations as VLC. A file named frame_00214.jpg tells you it was the 214th picture exported, so you have to divide by 4 to work out the second it came from. It also writes out every frame regardless of content, so a static slide held for two minutes yields 480 identical JPEG images.

Quick questions

How do I save a frame from a video on Windows 11?

Pause your video in VLC and press Shift+S to save a full-resolution PNG file into your Pictures folder. Recent releases of the Photos app include a Save a frame option in the timeline menu. Snipping Tool works as well, but it captures screen pixels rather than original video resolution.

How do I extract all frames from a video on Windows for free?

Run ffmpeg with a command like ffmpeg -i video.mp4 -vf fps=1 frame_%05d.jpg to output one image per second. VLC's scene video filter also handles this, but it requires playing the video through in real time. Neither of these free methods filters out duplicate pictures.

Why does VLC's scene filter save so few images?

The recording ratio value measures frame counts rather than seconds, and its default value is set to 50. On a 25 frames per second video, that default gives you one image every two seconds. Reduce the ratio number to capture more frames, or set it to match your video's frame rate to get roughly one image per second.

How many images is an hour of video?

Extracting 4 images per second generates roughly 14,400 files for an hour of video, while 1 image per second produces about 3,600 files. Dropping duplicate frames cuts those numbers down significantly on slide decks and screen recordings, but it makes little difference on continuous moving video.
