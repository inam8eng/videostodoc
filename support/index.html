Getting started

The first run is downloading something. What is it?

The speech engine, about 460 MB. It downloads once and lives in a models folder next to the app, so it moves with the app if you move the folder. After that first download, local video files work with no internet at all.

YouTube and other links still need a connection, because the video itself has to be fetched. That part is your own connection to the site, not an upload of your file to me. Nothing you process ever leaves your machine.

If the download is interrupted, close the app and open it again. It resumes rather than starting over.

Windows SmartScreen or my antivirus warns about VideoDoc. Is it safe?

It is a false positive, and it is worth explaining why rather than just asking you to trust me. VideoDoc is a Python program packaged into a single .exe. That packaging pattern is also used by people writing malware, so a few scanners flag the shape of the file rather than anything it does.

On the SmartScreen dialog, click More info, then Run anyway. If your antivirus quarantines the file, restore it and add the VideoDoc folder to your exclusions.

If you would rather verify than trust: every release ships a SHA256SUMS file. Compare the hash of your download against it, and you know the file you have is byte-for-byte the file that was built.

Your files

Where does VideoDoc save my documents?

On Windows, into an output folder next to the app. On Mac, into your home folder under VideoDoc. You never have to go looking: the app prints the full path under Your documents and opens the folder for you in one click.

Each video gets its own folder holding doc.pdf, a matching doc.md for notes apps, a plain transcript.txt, and an images folder of the on-screen captures. Tick Also save every frame and there is a frames folder too, with a frames_index.csv listing every image and the exact moment it came from.

If you installed the app somewhere Windows will not let it write, VideoDoc does not fail: it moves your documents to a writable location and tells you the new path.

Speed and reliability

A job is slow, or looks stuck.

It is not stuck. Every step runs under a safety timer. If one stalls, the app drops to your CPU or skips that one video and keeps the rest of the queue moving, and it says so plainly rather than sitting on a frozen progress bar. Cancel takes effect within a couple of seconds, even mid-step.

To make it genuinely faster:

  • Set PC power to Maximum to use every core.
  • On an NVIDIA card, accept the one-time GPU setup when offered. Transcription then runs on the graphics card, which is several times quicker.
  • For a YouTube video with captions, VideoDoc uses those instead of listening to the audio. That path is close to instant.
  • Also save every frame is the heavy option by design: an hour of video is around 14,400 images. The app warns you before it starts.
